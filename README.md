# ai-coding-lab

> 自由的灵魂。

这是 **ChatGPT × yichuan-dev** 的编程实验室。

这里不要求每一份代码都“有用”，也不要求所有东西都围着课程转。这里可以放 Java 小实验、网页、算法、小游戏、工具，以及以后突然冒出来的奇怪想法。

## 和 `java-from-zero` 的区别

- `java-from-zero`：你的 Java 学习主线，重点是你自己写、自己理解。
- `ai-coding-lab`：我们的实验场。我可以主动写东西、做小项目、留挑战题；你也可以随时拆、改、重写。

## 第一阶段

从 Java 基础开始，把“会看代码”慢慢变成“会做东西”。

## 一条规则

**能运行只是第一步，能看懂、能改、能解释，才算真正属于你。**

有些代码我会故意留一点悬念：先让你猜输出、找规律、自己改坏，再一起修回来。

## 安全提醒

这是公开仓库。不要提交密码、API Key、Cookie、验证码、身份证件、私人文件或其他敏感信息。
