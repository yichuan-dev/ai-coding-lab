# Number Guessing Game

这是一个“未来的你”项目。

现在看不懂全部代码完全正常，因为它故意提前用了几个还没正式学到的东西：

- `Scanner`：读取键盘输入
- `Random`：生成随机数
- `while`：重复执行，直到满足条件
- `if / else if / else`：根据不同情况做不同事情

## 现在可以怎么玩

先运行一次，感受它是干什么的。

然后只做三件事：

1. 找到决定随机数字范围的那一行。
2. 猜猜怎样把范围从 `1~100` 改成 `1~10`。
3. 不查答案，先自己改一次。

等你以后正式学完这些知识，再回来重写这个项目，不要只复制现在这份代码。

到那时，如果你能完全不用看这份代码重新做出来，这个项目才真正属于你。
