# 隐私说明

## DeepSeek API Key

API Key 只位于 `SessionKey` 的进程内存中；没有数据库、SharedPreferences、DataStore、文件或云端保存路径。完全退出或被系统结束进程后重新输入。关闭任务后新开 Activity 会清除旧 Key 与发送授权，即使旧进程仍然存活；结束 Activity 也主动清除。后台超过 30 分钟同样清除，使用单调时钟判断。输入框禁止保存状态及自动填充，默认隐藏字符；所有页面启用 FLAG_SECURE。

每次 HTTP 请求临时构造 Authorization，禁用重定向与缓存；没有 HTTP 日志和崩溃上报 SDK。可控的 char[]/byte[] 在用完后覆盖清除；Android/Java 网络栈内部短暂字符串只能交给系统回收，不承诺对 RAM 物理取证完全清零。

只向设置页明确确认过的 HTTPS AI 地址发送必要的上下文。模型与地址可改；改地址后清除旧 Key，需重新输入。初始地址为 DeepSeek 官方地址。错误提示不会展示服务返回的原始响应体或请求头。

## 手机本地资料

资料、简历、岗位、聊天、FAQ 和发送记录保存在应用私有目录，使用 Android Keystore 生成的 AES 密钥与 AES-GCM 加密。写入采用 AtomicFile；密文损坏会报错，不会悄悄覆盖成空白数据。禁用系统自动备份和设备迁移提取。

没有开发者服务器、统计 SDK、广告或用户账号系统。进行 AI 分析时，用户已确认的简历文字、资料、求职偏好、岗位和聊天上下文会发给用户指定的 AI 服务；因此“本地保存”不等于“AI 分析完全离线”。不发送简历原始附件给 AI。向 AI 提交前隐藏可识别的令牌、长号码和敏感请求头；不可将此过滤器视为能识别一切隐私的工具。

## BOSS 权限与登录

无障碍服务只处理 `com.hpbr.bosszhipin`，只在用户运行任务或明确读取控件时取其可见页面。可选通知监听器在入口立即丢弃其他 APP 的通知，只对 BOSS 发出通用提醒，不使用通知摘要直接发送回复。

不申请通讯录、短信、录音、相机、定位或全部文件访问权限。简历和备份通过 Android 文件选择器由用户选择。前台服务有可见的暂停与立即停止按钮；没有开机自动恢复发送。

BOSS 在官方 APP 中登录。助手不读取或保存其 Cookie/Session，也不能替另一 APP 删除登录状态。当前“临时使用”需要用户结束后在 BOSS 官方 APP 手动退出；需求中的助手托管临时/记住登录尚未实现。

遇到验证码、滑块、设备验证、登录过期、平台限制或页面不匹配，停止自动操作，通知本人处理。不破解验证码、不伪装设备、不绕过风控、不调用 BOSS 私有接口。

## 备份、清除和 GitHub

加密备份仅包含个人资料、求职设置及已授权 FAQ。备份使用 PBKDF2-HMAC-SHA256（150000 次）与 AES-GCM，密码至少 10 字符。没有 API Key、AI 主机配置、BOSS 会话、聊天、原始简历或发送账本。导入时校验字段和限额，并关闭首次沟通授权。

选择性清除聊天/岗位时保留去重账本。清除全部数据会同时删除本地密钥及去重记录，之后需要人工核对历史投递。已导出的备份需要在用户选择的位置自行删除。

GitHub 仅保存源代码、构建配置、公开许可、合成测试和说明。不提交真实资料、简历、密文数据库、BOSS 登录资料、API Key 或发布签名私钥。发布签名备份单独交给用户保存，用于以后安装同包名更新；它与 DeepSeek Key 完全不同。
